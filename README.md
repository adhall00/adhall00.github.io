# Anna’s Corner of the Internet

Each page is a separate HTML file. Open its file in GitHub, click the pencil to edit, and commit your changes to `main` to update GitHub Pages.

| Page | File |
| --- | --- |
| All About Anna | `index.html` |
| Baking | `baking.html` |
| Triathlon | `triathlon.html` |
| Publications | `publications.html` |
| Resume/CV | `resume.html` |
| Photo Gallery | `gallery.html` |
| Learn With Me buttons | `learn.html` |
| Fu–Liou Model | `learn/fu-liou.html` |
| The Discovery of the Stratosphere | `learn/stratosphere.html` |
| Future topics A–H | `learn/a.html` through `learn/h.html` |

Add lesson text inside the `<section>` where the comment says “Add your words below.” Write paragraphs as `<p>Your words here.</p>` and subheadings as `<h3>Your heading</h3>`. The Fu–Liou page already contains your original introduction.

To rename a placeholder, edit its button text in `learn.html`, then its heading and `<title>` in the corresponding lesson file. Keep the filename and link unchanged unless you also update the link.

`style.css` contains shared styling. `script.js` contains the cloud animation, baking cards, calendar, and redirects for old tab links. The header and navigation are present in each HTML page; update those across pages when changing the main menu. Images stay in `images/`.
